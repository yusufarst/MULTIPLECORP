# MultipleCorp — Company Management System

Status: REVIEW | Updated: 2026-09-27 | Owner: Planning

Internal, project-centered operations for a group of legal companies. The operational production V1 target is **15 October 2026**. Project identity and constraints belong to the [project charter](docs/00-governance/PROJECT_CHARTER.md).

This repository currently contains **P0 governance, continuity and proactive risk planning**. Application development has not started. The owner has delegated bounded technical planning improvements; this is not approval of business scope or implementation.

Start with [AGENTS.md](AGENTS.md), then [the context index](docs/CONTEXT_INDEX.md), [current state](docs/07-handoff/CURRENT_STATE.md), and [next action](docs/07-handoff/NEXT_ACTION.md). Humans and agents use the same documents.

The original owner brief and subsequent autonomy mandate are preserved in full; provenance and precedence are defined in [source of truth](docs/00-governance/SOURCE_OF_TRUTH.md). The [gap register](docs/00-governance/GAP_REGISTER.md) identifies concrete risks, decision owners and the phase in which each must be resolved.
