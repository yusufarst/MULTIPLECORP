## 18. Mandatory concurrency and failure scenarios

The Owner's working labels M-01–M-38 collide with no repository identifier and are kept as they are; no mapping table is needed. The Scenario column restates each scenario of DIR-032 §9; where this design qualifies the outcome stated there — M-13 for a deactivated actor, M-22 for two Owners acting on each other — the Outcome column says how. Each row is a P8 test with real PostgreSQL sessions (HO-11); after each, `ReconcileGuards` must report no difference (HO-12).
