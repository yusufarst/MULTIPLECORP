NONTECHNICAL USER USABILITY — HIGHEST DESIGN PRIORITY
Approach every workflow as a person who has never used MULTIPLECORP and has minimal knowledge of enterprise software.
Evaluate:

* Can the user understand the page immediately?
* Is the correct action obvious?
* Are menu names understandable in everyday Indonesian?
* Can the user find the next step without developer guidance?
* Are errors understandable and recoverable?
* Are mandatory fields obvious?
* Can the user complete tasks without losing information?
* Can users distinguish draft, saved, submitted, approved, and finalized states?
* Are potentially irreversible actions handled safely?
* Does the application provide meaningful feedback after every important interaction?

Avoid explaining confusing interfaces through additional paragraphs. Simplify the interfaces themselves.
