## 1. Conventions

| RC | Rule | Grounds |
| --- | --- | --- |
| RC-01 | **Paths** follow INFORMATION_ARCHITECTURE §11: lowercase Indonesian segments of the product map, `{id}` a public identifier (UUIDv7). A page's view is a GET at the page's route; a command is a state-changing request — POST at its record's path with an Indonesian verb segment, or without one at a collection's or a part's path whose noun names what the command creates, saves as a draft — new or existing —, sets, clears, changes or issues (ROUTE-123's `status`, ROUTE-182's `nota`, ROUTE-221's `dokumen`); PUT at the record's own path or one of its parts, without a verb segment, where it replaces the record's editable fields or the account's own setting; DELETE where it removes the account's own setting. No GET changes state, and every route lives in the web group under session and request-forgery protection. | IA §11; RB-01; RB-03; WS-04 |
| RC-02 | **Handlers** are named "module code + action": `PRJ CompleteProject` is the action class `CompleteProject` of ARCHITECTURE's Projects module, one class per command (ARCHITECTURE §§4–5); `Show…` names a page's controller method with its query class; `IMPORT` is the tier-7 import orchestration. The names are Level 1 choices (TECH-037), the module never. | ARCHITECTURE §§3–5 |
| RC-03 | **Capability and scope** are PERMISSIONS_MATRIX's: the capability the route declares (RB-02) or, beside a capability, the declared requirement SECURITY EN-03 accepts — "every active account (S0)" for a route whose content is S0 or whose every other part is gated by its own read class, "SELF" for the account's own row (AU-13; PJ-17) and "the enrolment-only session" for its routes (AU-18) (`DIR-081` OB-03) —, the company scope SF-CMD step 2 checks against the target's company — the Owner's covering every company (`scope.all_companies`) —, "the pool" for pooled stock (S1), and "none" only for the exceptions of SECURITY EN-03. A control is present only with its capability (AZ-01). | RB-02; AZ-01; EN-03; `DIR-081` OB-03 |
| RC-04 | **Protections.** *Identity:* every SF-CMD command carries `command_id` (CI-01), its family named — an AX- of WORKFLOWS §9 or an NX- of CONCURRENCY_IDEMPOTENCY §7.3; the authentication requests (CI-09), an upload, an export request and RB-10's own-locale change carry none (RB-03). *Step-up:* AU-15's password confirmation within 15 minutes, where it applies. *Rate class:* WS-12's — auth (fail closed), password change, search, scanner, uploads, exports, heavy reports, commands. *Background:* RB-05's — previews, thumbnails and polling only; a request that is not a GET is never background. | CI-01; CI-09; RB-03; RB-05; AU-15; WS-12 |
| RC-05 | **Results.** *Success:* COMMITTED, the answer in place (IP-01) and the destination the page's NAV- contract names. *Validation:* the answer at the fields, the input kept (IP-14). *Error:* REJECTED with its rule code and message (IP-01), CONFLICT on a stale version (IP-03), FAILED with a retry under the same `command_id` (IP-04), an unknown or out-of-scope record and an Owner-only address answered by PG-005 with MSG-09, identical for each, and a record in scope without the capability with MSG-10 (IP-21; AZ-11), an expired session re-authenticated in place (IP-11). Each row names what it adds. | IP-01–IP-04; IP-11; IP-14; IP-21 |
| RC-06 | **A visible control without a route** is marked in §4 — client-only, intentionally disabled or intentionally hidden (AICWDF §14.3): visible, clickable and not implemented is forbidden. | AICWDF §14.3 |
