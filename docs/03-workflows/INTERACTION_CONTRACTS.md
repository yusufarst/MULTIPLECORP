## 1. Conventions

| IG | Rule | Grounds |
| --- | --- | --- |
| IG-01 | **Visible to** is the capability that makes the control present; without it the control is absent, never disabled (AZ-01; H7-03). | AZ-01 |
| IG-02 | **Answers.** COMMITTED — MSG-01, with MSG-05 while derived work such as a rendition is pending (IP-01; IP-12); REJECTED — MSG-02 with its rule in business words; CONFLICT — MSG-03, or MSG-04 when already recorded (IP-03); FAILED — MSG-06 or MSG-07 with "Coba Lagi" under the same `command_id` (IP-04); not found or out of scope — MSG-09, identical (IP-21; AZ-11); forbidden — MSG-10; a session that ended — MSG-11, the input kept (IP-11); a validation summary — MSG-12 with each field's answer (IP-14); a lost connection before sending — MSG-13; a limit — MSG-20. A contract names only what it adds. | IP-01–IP-04; IP-11; IP-12; IP-14; IP-21 |
| IG-03 | **Confirmations.** An irreversible command asks MSG-39 first (IP-08); a correction, closure or destructive action asks its reason, MSG-40 (IP-09); a guarded one the step-up, MSG-27, when 15 minutes have passed (IP-10; AU-15). Their "Kembali" returns to the form, the input kept (NV-02). | IP-08–IP-10 |
| IG-04 | **Back and cancel** are the page's NAV- contract's; leaving with unsent input asks MSG-35. | NV-01; NV-02 |
| IG-05 | **Tests.** Every contract's test proves, through the route, the control present with its capability and absent without it — for a SELF or every-account control, present with its session state and absent without it —, the success, the validation answer and each rejection the contract names; an SF-CMD command's test also replays one `command_id` and gets the recorded outcome (CI-05); a guarded command's test lets the step-up expire (AU-15); a journey's E2E test walks it at the desktop and phone widths of its journey (S2-J01–S2-J06). | CI-05; AU-15; AICWDF §19 |

## 3. Command interactions — INT-101 onward

One contract for each command or request of ROUTE_CONTRACTS §3, its number the route's, grouped as the routes are. *Error* names what a contract adds to IG-02; *Back / cancel* what it adds to IG-04. *Validation* "MSG-12 at the fields (IP-14)" answers a command's fields: a command without fields — a revoke, an end of session, a confirmation-only command — has none, and its test names none. A route that §2 already contracts keeps its row here only as a pointer to that contract, so one control has one contract.
